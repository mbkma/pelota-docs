Welcome! These pages are for everyone who is curious about Pelota, whether you want to play
it, understand how it works, or help build it. No programming knowledge is needed to read
them: every concept is explained in plain words first, with diagrams and plots where they help.

## Where to start

- **You want to play:** start with [Play](play/), then read [Hitting well](play/hitting-well/).
- **You wonder why the game behaves the way it does:** for example how pressure is worked out,
  or why the AI suddenly plays a short angle. Pick a topic from
  [How it works](how-it-works/). Each page starts with the short version and then goes deeper.
- **You want to help:** [Contribute](contribute/) lists the ways to get involved and walks you
  through your first contribution.

{{< callout type="info" >}}
Pelota is a work in progress. These pages describe the game as it is today; when something
changes in the game, the matching page should change with it. If you notice a difference,
please [tell us](contribute/testing/) or fix it yourself with the **Edit this page** link.
{{< /callout >}}
